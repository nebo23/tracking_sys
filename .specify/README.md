# Specification workspace
This directory contains shared project principles and reusable templates for specification-led delivery.

It is not personal assistant configuration. Specify CLI has not been installed or initialized, and there are no generated agent commands or active-feature metadata.

- `memory/constitution.md`: proposed project principles.
- `templates/`: reusable requirements, plan, and task templates.

See [Engineering workflow](../docs/engineering/workflow.md) before adopting a specific Spec Kit release.
