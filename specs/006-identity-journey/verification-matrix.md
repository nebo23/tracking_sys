# Specification 006 verification matrix

Status: **proposed, not executed** (2026-11-11). Prepared against [design revision 4](design.md) and the [decision packet](decision-packet.md). The [review register](preparation-review.md#finding-coverage) maps findings R006-01 to R006-22 to these cases. Every case uses synthetic agencies, clients, identifiers (`example.test` emails, fictional phone digits) and tokens on a disposable PostgreSQL database. Assertions inspect stored rows, response bodies and outgoing browser bytes, not helper calls. Where a case checks the write API, it compares the external response separately from the internal outcome, stored rows and change records. Cases that depend on time (retry windows, retention, expiry) move a controlled test clock.

Acceptance criteria (spec.md): **AC1** anonymous visits link only within the same client under applicable consent; **AC2** shared or conflicting identifiers do not merge without a policy; **AC3** a shared-device switch does not transfer visits; **AC4** merge/unmerge preserves provenance and triggers recalculation without losing evidence.
