# Backend
Reserved for the FastAPI application, integrations, and background processing.

- `app/`: application source.
- `migrations/`: versioned database changes.
- `tests/`: backend validation.
- `requirements.txt`: Python dependency manifest; currently a planning placeholder without selected packages.

No executable scaffold exists. Begin implementation only after approval of spec 001.

Install approved Python dependencies inside a project virtual environment or container only. Keep the host virtual environment out of version control and container build inputs. See [environment readiness](../docs/engineering/local-environment.md).
